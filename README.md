### 👨‍💻 About me

I'm a backend engineer with **10+ years** of experience designing and building **Java microservices on AWS**. Most of my recent work is **legacy modernization**: turning SOAP services and monoliths into cloud-native, serverless REST APIs that are faster, cheaper to run and easier to maintain.

- 🏢 **Senior Consultant at Deloitte**, leading a team that moves legacy applications to the cloud
- ☁️ I build serverless REST APIs with **Quarkus** and **Spring Boot** on AWS and **Red Hat OpenShift (ROSA)**
- 🔁 I automate infrastructure and delivery with **CloudFormation**, **CodePipeline** and **Tekton**
- 🛡️ I care about quality: **TDD**, **JUnit/Mockito**, **SonarQube** and **Veracode**-clean code
- 🌍 I run **multi-region deployments with failover** for high availability
